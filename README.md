# Moxacg 网站联动（astrbot_plugin_zibll）

面向 WordPress / Zibll（子比）主题网站的 AstrBot 群聊插件。群成员可以绑定自己的网站账号，在群内查看个人资料、签到，以及获取最新文章和搜索文章标题。管理员可以在 AstrBot 后台自定义指令。

**本插件需要配套的 WordPress 桥接插件 `astrbot-zibll`，不能只安装 AstrBot 端。** 默认网站地址为 `https://moxacg.moe`，也可以配置为其他已部署桥接插件的 Zibll 网站。

## 功能说明

| 功能 | 说明 |
| --- | --- |
| 账号绑定 | 通过网站正常登录授权，再回到原群核对昵称和 UID，二次确认绑定；无需向机器人发送网站密码或 Cookie。 |
| 个人资料 | 显示本人头像、昵称、加入网站天数、成长等级、UID、积分、已发布文章数和评论数。头像获取失败时仍返回文字资料。 |
| 网站签到 | 复用 Zibll 的签到状态和积分、经验奖励逻辑，显示签到结果、当前积分、连续签到和累计签到天数。 |
| 最新文章 | 按发布时间获取公开文章，返回标题、发布时间和网站链接，默认 5 条。 |
| 文章搜索 | 按标题关键词搜索公开文章，关键词为 1–60 字，默认返回 5 条。 |
| 授权管理 | 支持群内两步解绑，也可登录网站撤销本人授权。 |
| 自定义指令 | 七项指令均可在 AstrBot 插件配置中修改，保存并重载后生效。 |

资料与签到仅针对当前群成员绑定的本人账号，不接受指定任意 UID 查询或代签。最新文章与搜索不要求绑定，但仍受两端群白名单限制。插件不在私聊中响应。

## 安装准备

- 已运行的 AstrBot，以及能够接收群消息的适配器。
- 已启用 Zibll 主题的 WordPress 网站，桥接插件要求 PHP 8.0 或更高版本。
- 正式网站使用 HTTPS，并启用 WordPress 固定链接；机器人可访问桥接 API，群成员的浏览器可访问网站授权页面。
- 两个安装包：网站端 `astrbot-zibll.zip`、机器人端 `astrbot_plugin_zibll.zip`。本项目交付包位于项目根目录的 `打包产物` 文件夹。
- AstrBot 端依赖见 `requirements.txt`：`aiohttp>=3.9,<4`、`Pillow>=10`。

签到还要求适配器提供有效的原始消息 ID 和消息时间；缺失或无效时，插件会拒绝签到，而不是绕过校验。

## 安装与配置

### 1. 安装网站桥接插件

1. 在 WordPress 后台的插件安装页面上传 `astrbot-zibll.zip`，安装并启用。
2. 打开 **设置 → AstrBot 网站联动**，检查页面显示的主题能力是否可用。
3. 点击 **生成 / 轮换密钥**，记录页面显示的 `Client ID`、`Key ID` 和新共享密钥。
4. 在允许群列表中填写群范围，每行一项，格式见下一节。
5. 勾选 **启用认证接口**，点击 **保存设置**。正式站点不要勾选本机 HTTP 调试。
6. 将页面显示的 API 地址、公开网站地址及三项凭证填入 AstrBot 端。

共享密钥只在生成时的响应中显示。遗失后需要重新生成；轮换会使旧密钥立即失效，必须同步更新 AstrBot 端的 `key_id` 和 `shared_secret`，再重载插件。

### 2. 设置两端群白名单

每一项必须使用完整范围：

```text
平台实例ID|机器人自身ID|群ID
```

例如，以下是假值，必须替换为实际事件中的身份：

```text
onebot-instance|100001|200001
```

- 平台实例 ID 对应 AstrBot 事件的 `get_platform_id()`，不是简单的平台名称；机器人自身 ID、群 ID 分别对应 `get_self_id()`、`get_group_id()`。
- WordPress 后台每行填写一项；AstrBot 的 `allowed_groups` 列表每项填写同一个完整字符串。
- 两端必须完全一致，保留 ID 中的前导零，不添加空格，不使用通配符；最多 100 项。
- 空列表不开放任何群，不能仅填写群号。

### 3. 安装 AstrBot 插件

1. 在 AstrBot WebUI 的插件管理中，通过本地 ZIP 安装方式上传 `astrbot_plugin_zibll.zip`。
2. 打开 **Moxacg 网站联动** 的插件配置，填写网站地址、凭证和 `allowed_groups`。
3. 按需调整文章条数、头像域名和指令。
4. 将 `enabled` 设为 `true`，保存并重载插件。
5. 检查 AstrBot 日志，连接验证成功时会出现：

```text
AstrBot-Zibll 认证连通验证通过。
```

若验证失败，先检查配置并重载，不要仅凭插件出现在列表中判断连接成功。

### 配置项

| 字段 | 默认值 | 用途 |
| --- | --- | --- |
| `enabled` | `false` | 启用网站联动；配置完整后开启。 |
| `api_base_url` | `https://moxacg.moe/wp-json/astrbot-zibll/v1` | 网站后台显示的 API 基址，必须以 `/wp-json/astrbot-zibll/v1` 结尾。 |
| `public_site_url` | `https://moxacg.moe` | 群成员访问的网站地址，必须与桥接后台显示的公开网站地址一致。 |
| `client_id` | 空 | 网站生成的 Client ID。 |
| `key_id` | 空 | 网站当前有效的 Key ID。 |
| `shared_secret` | 空 | 网站生成的 64 位小写十六进制共享密钥。 |
| `allowed_groups` | `[]` | 允许群范围列表，格式见前文。 |
| `allow_local_http` | `false` | 仅用于显式开启的环回地址 HTTP 调试，正式站点保持关闭。 |
| `request_timeout` | `15` | 请求总超时秒数，范围 3–30；连接超时最多 3 秒。 |
| `latest_count` | `5` | 最新文章返回条数，范围 1–10。 |
| `search_count` | `5` | 搜索返回条数，范围 1–10。 |
| `avatar_hosts` | `[]` | 额外允许的头像域名；默认已允许网站域名。 |
| `commands` | 见指令表 | 七项指令名称，修改后保存并重载。 |

若头像使用 CDN，在 `avatar_hosts` 中添加真实的精确域名，例如 `cdn.example.com`，不要包含协议、端口、路径或通配符。

## 指令与使用方法

以下使用默认指令。发送时仍需满足 AstrBot 核心唤醒条件：使用配置的唤醒前缀，或实际 **@机器人并发送完整指令**。例如，实际 @机器人后输入 `/网站资料`，不要因为已经 @ 就自行删掉指令中的 `/`。

| 配置项 | 默认指令 / 示例 | 用途 |
| --- | --- | --- |
| `commands.bind` | `/网站绑定` | 发起网站账号绑定。 |
| `commands.confirm` | `/网站绑定确认`、`/网站绑定确认 123` | 查看待确认账号，再用真实 UID 完成绑定。 |
| `commands.unbind` | `/网站解绑`、`/网站解绑 确认` | 预览当前绑定，再确认解除授权。 |
| `commands.profile` | `/网站资料` | 查询本人网站资料，需先绑定。 |
| `commands.checkin` | `/网站签到` | 为本人网站账号签到，需先绑定。 |
| `commands.latest` | `/网站最新` | 获取最新公开文章。 |
| `commands.search` | `/网站搜索 子比` | 搜索标题包含“子比”的公开文章。 |

### 绑定网站账号

1. 在已允许的群内发送 `/网站绑定`，取得授权链接。
2. 在 10 分钟内打开链接，正常登录本人网站账号，核对页面中的群和成员身份后授权。
3. 回到发起绑定的原群，发送 `/网站绑定确认`，查看待确认的昵称和 UID。
4. 确认是本人账号后，发送 `/网站绑定确认 实际UID`，例如 UID 为 123 时发送 `/网站绑定确认 123`。
5. 收到绑定成功提示后，即可查询资料和签到。

如果昵称或 UID 不属于自己，不要确认；重新发送 `/网站绑定` 获取新链接，旧挑战会失效。不要转发授权链接。

同一个群范围内，一个网站账号只能绑定一个群成员；同一成员在不同群中需要分别授权。跨群绑定不会增加同一网站账号每天的签到次数。

### 查询资料与签到

绑定后，分别发送：

```text
/网站资料
/网站签到
```

资料中的加入天数按网站日期计算，注册当天计第 1 天；等级指成长等级，不是 VIP 等级；积分不是经验值。积分或成长等级未开启时显示“网站未启用”。文章数按主题的已发布普通文章统计，评论数按主题的已审核评论统计，论坛开启时可能包含论坛评论。

签到以网站日期和 Zibll 已开启的签到规则为准，网页签到与群内签到共用状态。当天已经签到会返回“今日已签到”，不会按群重复发奖。

签到超时后插件只查询状态，不自动重发签到写入。如果提示“结果需要核实”或“结果未知”，请先到网站查看签到记录，必要时联系站长核对，不要反复发送指令或直接补发奖励。

### 获取和搜索文章

```text
/网站最新
/网站搜索 子比
```

文章查询仅面向可公开展示的普通文章（`post`），返回标题、发布时间和链接，不返回正文。搜索只匹配标题，不是全文搜索；结果数量受配置和可见文章数量限制。

### 解除绑定

在原群发送 `/网站解绑` 查看即将解绑的 UID，再在两分钟内发送 `/网站解绑 确认`。

也可以在浏览器登录本人网站账号，打开网站授权管理页面撤销授权。默认网站的管理地址为：

```text
https://moxacg.moe/?az_bindings=1
```

其他网站使用其桥接后台显示的“用户撤销授权”地址。

### 自定义指令

在 AstrBot 插件配置的 `commands` 中修改对应字段。例如，将 `profile` 改为 `/我的资料`，保存并重载后使用 `/我的资料` 查询。

七项指令必须全部配置、互不重名，每项为 1–32 个字符，不能包含空白或控制字符。确认、解绑和搜索仍按指令表所示方式附加参数；其他指令不接受额外参数。

## 使用注意事项

- 只接受纯文本和对本机器人的 @。引用回复、转发、图片或包含其他 @ 的消息不会执行这些指令。
- 同一成员在同一群范围内有 3 秒操作冷却，网站端另有限流；连续完成绑定步骤时请稍作间隔。
- 绑定后查询的资料会展示在群内，包括积分，请在授权前确认是否愿意公开。
- 两端通过 HMAC 签名认证，并校验群范围和请求重放；共享密钥应仅由站长和机器人管理员保管，不要将密钥、Cookie 或完整授权链接用于公开排错截图。
- 网站反向代理应让 WordPress 正确识别 HTTPS。共享缓存不能缓存桥接接口 `/wp-json/astrbot-zibll/v1/*`、授权页面及其登录态响应，应保留这些响应的禁止缓存设置。

## 常见问题

| 现象 | 检查方法 |
| --- | --- |
| 发送指令完全没有响应 | 检查插件是否启用并重载、是否在群内、两端完整群范围是否一致，以及核心唤醒条件和指令拼写；不要使用引用回复或混入图片。 |
| 提示连接尚未通过验证 | 检查 API 地址、公开网站地址、三项凭证、HTTPS 和机器人到网站的网络连通性，查看日志后重载。 |
| 提示认证失败 | 确认两端 Client ID、Key ID、共享密钥一致，轮换后已同步，并检查两端服务器时间。 |
| 提示网站拒绝请求 | 检查网站群白名单和 HTTPS 配置；通过反向代理访问时不要绕过 HTTPS 校验。 |
| API 返回 404 或 HTML 页面 | 检查 WordPress 桥接是否启用、固定链接是否有效，以及安全插件、WAF 或登录拦截是否阻止 API 请求。 |
| 资料有文字但没有头像 | 检查头像真实域名是否在 `avatar_hosts` 中，以及头像是否可从机器人服务器访问、格式是否有效。 |
| 绑定链接过期或 UID 不符 | 重新发起绑定，登录本人账号授权后再核对；不要确认他人的 UID。 |
| 签到提示消息 ID 或时间无效 | 检查适配器是否提供可靠的消息 ID 和时间，不要以随机 ID 或伪造时间绕过检查。 |
| 签到提示需要核实 | 到网站查看签到状态和奖励记录，必要时联系站长，不要自动补签或补奖。 |
